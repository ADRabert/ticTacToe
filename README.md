# Tic-Tac-Toe Website

## Details
This repository contains a tic-tac-toe game that is playable through a web browser.

### How it works
- Each player takes turns by placing their symbol on one of the tiles on the board
- If a player gets three in a row, column or diagonally, they win and receive a point
- If no player wins, the game is declared a tie, and is added to the respective counter
- Declares who the winner is by changing the header text
- Uses vector images for the symbols instead of text
- If a game ends on a player's last turn, the other player goes first next game
